# **App Name**: DocuMatch AI

## Core Features:

- Document Upload: User-friendly drag-and-drop interface for uploading two documents.
- Document Processing: Utilize the OpenAI API, with the API key securely stored in a .env file, to process and analyze the uploaded documents.  This feature is a tool which assesses the meaning and concepts within each document.
- Similarity Scoring: Employ Langchain to compute a similarity score between the two processed documents.
- Similarity Score Display: Display the computed similarity score in an intuitive format, such as a percentage.

## Style Guidelines:

- Primary color: HSL 214, 77%, 47% (RGB hex: #3d84e6) for a professional, trustworthy feel.
- Background color: HSL 214, 20%, 95% (RGB hex: #f0f4fa) for a clean and modern look.
- Accent color: HSL 184, 57%, 44% (RGB hex: #3baea0) to highlight key actions and elements.
- Body text font: 'Inter' sans-serif for clear, readable text. Headline font: 'Space Grotesk' sans-serif for headings and titles.
- A clean, single-page layout focusing on the drag-and-drop areas and similarity score display.
- Subtle animations to indicate processing and score updates.
- Simple, recognizable icons to represent document types and actions.
